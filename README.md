# 超級井字棋 Ultimate Tic-Tac-Toe

九宮格裡的九宮格:大棋盤有 9 個小棋盤,每個小棋盤都是一盤井字棋(OOXX)。網頁版,手機、電腦都能玩。

**線上玩:** https://smaragdinex.github.io/ultimate-tictactoe/

## 玩法

1. 你下在小棋盤的哪一格,對手下一手就要去大棋盤的同一個位置(那個小棋盤會發亮)。
2. 在小棋盤連成一線,就贏下那個小棋盤。
3. 被送去的小棋盤已經分出勝負或下滿,就可以下在任何還能下的小棋盤。
4. 在大棋盤贏下三個連成一線的小棋盤就獲勝;都下完沒有人連線是和局。

## 模式

- **跟電腦玩**:簡單 / 普通 / 困難,可選先手或後手,可以悔棋。
- **線上對戰**:建立房間拿到 4 碼房間號和 QR code,對手用手機掃碼或輸入房間號加入;每局換邊先下。
- **兩人同一支手機**:輪流下。

## 電腦 AI:蒙地卡羅樹搜尋(MCTS)

`js/mcts-worker.js`,在 Web Worker 裡跑(算的時候畫面不會卡)。每一輪:

1. **選擇**:從目前局面往下,用 UCB1 公式在「勝率高的步」和「還沒試過幾次的步」之間取捨;
2. **展開**:走到沒探索過的局面,加一個新節點;
3. **模擬**:從那裡隨機下到分出勝負;
4. **回傳**:把輸贏一路記回路上的每個節點。

時間到了選被走最多次的那一步。難度 = 每步思考時間(簡單 0.15 秒且有時亂下、普通 0.8 秒、困難 2 秒),普通難度每步大約模擬上萬盤。

## 技術

- 純 HTML / CSS / JavaScript(ES modules),不用建置工具;GitHub Pages 直接放。
- 規則:`js/game.js`;畫面與流程:`js/main.js`。
- 線上對戰:[PeerJS](https://peerjs.com/)(WebRTC 點對點),用 PeerJS 公開的配對伺服器,不用自己架伺服器;QR code 用 qrcode-generator。
- 本機測試:`python3 -m http.server` 後開 `http://localhost:8000`。
